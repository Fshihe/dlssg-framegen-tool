# DLSSG 帧生成一键开启工具

给 RTX 20/30 系显卡开 DLSS 帧生成的小工具。单个 exe，不用装 Python，不用联网。

底层是 [sdli1995/dlssg_for_sm86](https://github.com/sdli1995/dlssg_for_sm86)，我这里只是做了个壳。

## 为什么做这个

上游那个 Mod 用起来要手动做三件事：

1. 判断自己显卡该用 SM86 还是 SM75 路由
2. 自己写 `dlssg_sm86.ini`
3. 找到游戏真正在渲染的那个 exe

第三步最容易错。黑神话是 `b1\Binaries\Win64\b1-Win64-Shipping.exe`，
放到外层的启动器目录或者 Engine 目录，游戏照样启动、一点提示都没有，但 Mod 就是不生效。

这个工具把这步自动化了。

## 用法

打开 exe，左边列表里选游戏，点「一键安装」，完事。

装完进游戏，画面设置里打开「帧生成」，选 2X / 3X / 4X。

列表里带 ★ 的是能装的（64 位 + D3D12）。没有的游戏可以点「浏览游戏文件夹」手动选。

装之前建议先点一下「预览将要做的改动」，会告诉你要往哪个目录写哪两个文件，确认一下位置对不对。

## 常见问题

### 游戏提示「您的显卡不支持 DLSS 帧生成技术」

先查**硬件加速 GPU 计划**。

帧生成必须开着这一项，关掉的话连 40 系也用不了，但游戏只会说「显卡不支持」，
很容易以为是 Mod 出了问题。

我调试的时候就踩了这个坑：Mod 日志显示已经连上 NGX 帧生成特性了，游戏还是弹这个框，
最后发现是这一项关着。开了就好了。

工具环境面板里会显示状态，红字就是没开，点右边的按钮开启，**然后重启电脑**。

这一项如果本来就是开的，再往下看：

- **游戏完全退出了吗** —— 要整个退出进程再启动，回主菜单重开一局不算
- **游戏本身有没有帧生成功能** —— 进画面设置看看有没有这个选项。游戏压根没做的，工具也变不出来。
  本来就能看到这个选项（哪怕是灰的）的成功率最高
- **换个代理入口** —— 选项里把「代理入口」从自动改成 `winmm.dll`，重新安装
- **显存不够** —— 插帧要额外占显存，2K 大概 500MB，4K 大概 700MB

还不行就取个证，命令行跑：

```
DLSSG帧生成一键开启工具.exe collect "游戏目录"
```

诊断包会生成在 `%LOCALAPPDATA%\DLSSG-SM86-Tool\reports\`，
里面包含 Mod 的运行日志，发出来就能看出卡在哪一步。

### 杀软报毒

正常的。上游那几个 dll 都会被启发式引擎误报，因为工作方式就是 DLL 代理加 hook。
dll 带自签名证书，可以在文件属性 →「数字签名」里看到。

### 装了没效果

先用「预览将要做的改动」确认写入目录对不对，应该和游戏主程序在同一个文件夹。

## 实测

《黑神话：悟空 性能测试工具》上跑的：

| 显卡 | 倍率 | 开启前 | 开启后 |
|---|---|---|---|
| RTX 3070 | 3X | 41 FPS | 105 FPS |
| RTX 2070 笔记本 | 2X | 40 FPS | 65 FPS |

两台机器都没发现画面异常。

提升幅度跟显卡关系很大，卡越弱、插帧本身的开销占比越大，提升就越小。
不同游戏之间的差别也会很大，别拿上面的数字当预期。

## 支持情况

| 显卡 | 路由 |
|---|---|
| RTX 30 系（3050~3090，含 Ti、笔记本版） | SM86 |
| RTX 20 系（2060~2080，含 Super / Ti、笔记本版） | SM75 |
| RTX 40 / 50 系 | 不用这个，本来就能开 |
| GTX 16 系及更早、A 卡、核显 | 硬件不支持 |

游戏需要 Direct3D 12，Vulkan 的暂时不支持（上游说下一版做）。

20 系只在 2070 笔记本上实测过，其他型号是按架构推断的。

## 卸载

工具里点「卸载并还原」，会删掉放进去的文件，并把覆盖掉的原文件还原回去。

想彻底清干净，把 `%LOCALAPPDATA%\DLSSG-SM86-Tool\` 这个文件夹删掉就行。

## 安全说明

- 只往游戏目录写两个文件：代理 dll 和 `dlssg_sm86.ini`
- 覆盖前先备份，写完校验哈希，中途出错会整体回滚
- 不写注册表、不装驱动、不改系统设置。唯一例外是环境面板里那个
  「开启硬件加速 GPU 计划」按钮，点了会改一个注册表值（跟 Windows 设置里那个开关是同一件事），
  点之前会弹窗让你确认
- 检测到反作弊组件会直接拒绝安装

**联机游戏注意**：DLL 代理注入这种方式，带反作弊的游戏有封号风险，
工具会拦住，建议只用在单机游戏上。

## 命令行

同一个 exe 也能当命令行用：

```
DLSSG帧生成一键开启工具.exe detect                看显卡环境
DLSSG帧生成一键开启工具.exe list --d3d12          列出能装的游戏
DLSSG帧生成一键开启工具.exe check "<目录>"        安装前预检
DLSSG帧生成一键开启工具.exe plan "<目录>"         预演，不写入
DLSSG帧生成一键开启工具.exe install "<目录>" -y   安装
DLSSG帧生成一键开启工具.exe uninstall "<目录>"    卸载
DLSSG帧生成一键开启工具.exe hags                  查硬件加速GPU计划
DLSSG帧生成一键开启工具.exe collect "<目录>"      收集诊断包
DLSSG帧生成一键开启工具.exe selftest              85 项自检
```

## 自己编译

```
python tools\fetch_payload.py
python build.py
```

payload 里的 dll 不在仓库里，上面第一条命令会从上游下载并校验 SHA256。
打包需要 pyinstaller。

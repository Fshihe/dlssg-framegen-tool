# 兼容性反馈指南

本工具能不能用，**取决于游戏自身是否提供帧生成能力**，而这在各游戏之间差异极大。
所以兼容性反馈非常有价值 —— 你的一次测试能帮到后面所有人。

---

## 提交反馈前，先自己做三步排查

1. **硬件加速 GPU 计划（HAGS）开了吗？**
   这是帧生成的硬性系统前置条件。工具环境面板会显示状态，红字就是没开。
   **绝大多数「提示显卡不支持」都是这个原因。**
2. **游戏完全退出再重启了吗？** 是「完全退出进程再启动」，不是回主菜单重开一局。
3. **游戏本身有这个选项吗？** 进画面设置看看有没有「帧生成 / Frame Generation」。
   已经能看到（哪怕灰着）的游戏成功率最高；压根没有这个选项的游戏，Mod 也变不出来。

---

## 一键生成反馈材料

```bat
DLSSG帧生成一键开启工具.exe collect "<你的游戏目录>"
```

会在 `%LOCALAPPDATA%\DLSSG-SM86-Tool\reports\` 下生成一个 `诊断包-xxxx.txt`，
里面包含：显卡与系统环境、HAGS 状态、安装状态、INI 内容、以及 **Mod 的运行日志**。

**把这个文件贴出来**（或上传到 pastebin / GitHub issue），比任何文字描述都有用。

## Mod 日志怎么看（如果你想自己先判断）

日志位置：`<游戏目录>\dlssg_sm86\logs\native_<PID>.jsonl`
（需要安装时把日志级别设为 **运行诊断（Level=2）**，默认 Level=1 只记错误）

| 日志内容 | 含义 |
|---|---|
| 有 `"event":"configuration"`，且 `"router":86` 或 `75` | ✅ Mod 已加载，且读到了正确路由 |
| 有 `"event":"ngx_driver_connected"`，`"feature_id":11` | ✅ 已连上 NGX 帧生成特性（11 = Frame Generation） |
| 有 `"event":"runtime_redirect"` | ✅ 已成功劫持游戏对 `nvngx_dlssg.dll` 的加载请求 |
| **完全没有日志目录** | ❌ 游戏没加载这个代理 DLL → 换个代理入口（winmm / dinput8 / winhttp / dxgi）重装 |

**重要**：日志里出现 `ngx_driver_connected` 只说明 Mod 接入成功，
**不代表游戏一定会显示帧生成选项** —— 游戏可能有自己的判断逻辑。
如果 Mod 日志正常但游戏仍不给选项，请把诊断包发出来，这是最需要收集的情况。

## 已知会失败的情况（不用反馈了）

- **GTX 16 系 / 10 系 / AMD / Intel 显卡** —— 硬件上不支持帧生成
- **RTX 40 / 50 系** —— 原生支持，用不着本工具
- **Vulkan 游戏** —— 当前版本只支持 D3D12（上游列在下一版计划里）
- **带反作弊的联机游戏** —— 工具会主动阻止，强行使用有封号风险
